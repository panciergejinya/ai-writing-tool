# AIライティングツール 設計書

- 日付: 2026-09-17
- 対象: 個人用AIライティングツール

## 概要

ブログ記事執筆・メール返信文作成・文章要約・翻訳の4つのライティング系AI機能を1つのStreamlitアプリにまとめた個人用ツール。Gemini APIを利用してテキスト生成を行う。データベースや認証機能は持たない。

## 技術スタック

- Python
- Streamlit(マルチページアプリ)
- Gemini API(`google-genai` 公式SDK、モデル: `gemini-2.5-flash`)
- `python-dotenv`(APIキー管理)

## アーキテクチャ・ディレクトリ構成

```
AI_app/
├── app.py                      # ホーム画面(ツール概要・使い方)
├── pages/
│   ├── 1_📝_ブログ記事執筆.py
│   ├── 2_✉️_メール返信.py
│   ├── 3_📄_要約.py
│   └── 4_🌐_翻訳.py
├── utils/
│   ├── gemini_client.py        # Gemini API呼び出しの共通ラッパー
│   └── prompts.py              # 機能ごとのプロンプトテンプレート
├── .env                        # GEMINI_API_KEY=xxx (gitignore対象)
├── .env.example                # キー欄が空のサンプル
├── .gitignore
├── requirements.txt
└── README.md
```

- Streamlitの`pages/`ディレクトリ規約に従い、サイドバーに自動でナビゲーションリンクが生成される。
- `utils/gemini_client.py`が「モデル初期化」「プロンプト送信→テキスト取得」「APIエラー時の例外処理」を1関数にまとめ、各ページから呼び出す。
- `python-dotenv`で`.env`から`GEMINI_API_KEY`を読み込む。
- 生成結果の永続化(DB・ファイル保存)は行わない。`st.session_state`での一時保持のみで、ページリロードで消える。

## 各機能の詳細仕様

### 📝 ブログ記事執筆AI

- 入力:
  - テーマ/キーワード(必須、テキスト入力)
  - 文字数目安(選択: 短め約600字 / 標準約1200字 / 長め約2000字)
  - トーン(選択: フォーマル / カジュアル / 専門的)
- 出力: タイトル案+本文(見出し構造付き)をMarkdownで表示。コピー用テキストエリアにも出力。

### ✉️ メール返信AI

- 入力:
  - 受信メール本文(必須、貼り付け)
  - 返信の方向性(選択: 承諾 / 辞退 / 質問する / お礼 / その他自由記述)
  - 口調(選択: 丁寧 / ビジネスカジュアル)
- 出力: 件名案+返信文案をテキストエリアに出力。

### 📄 要約AI

- 入力:
  - 要約したい本文(必須、貼り付けのみ対応。ファイル/URL対応は今回スコープ外)
  - 要約の長さ(選択: 一言 / 3行 / 詳細)
- 出力: 箇条書きまたは短文の要約テキスト。

### 🌐 翻訳AI

- 入力:
  - 原文(必須、貼り付け)
  - 翻訳方向(選択: 日→英 / 英→日。日本語⇔英語のみ対応)
  - トーン(選択: 自然 / フォーマル)
- 出力: 翻訳文をテキストエリアに出力。

各ページ共通のフロー: 「生成」ボタン押下 → 入力バリデーション → `st.spinner`表示 → Gemini API呼び出し → 結果表示。

## 共通モジュール設計

### `utils/gemini_client.py`

- 公式SDK `google-genai` を使用、モデルは `gemini-2.5-flash`。
- `generate_text(prompt: str) -> str` の1関数を提供。内部でクライアント初期化・呼び出し・例外catchを行う。
- `.env`に`GEMINI_API_KEY`が無い場合はアプリ起動時に`st.error`で警告し、以降の処理を止める。

### `utils/prompts.py`

- 機能ごとに`build_blog_prompt(...)` `build_email_reply_prompt(...)` `build_summary_prompt(...)` `build_translation_prompt(...)`のような関数を用意。
- UIで選んだオプション(文字数・トーン等)を埋め込んだプロンプト文字列を返す。
- 各ページはUIの値を集めてこの関数に渡すだけにする。

## エラーハンドリング

- 入力必須項目が空のまま「生成」を押した場合は`st.warning`で入力を促し、API呼び出しは行わない。
- API呼び出し中は`st.spinner`を表示。
- 失敗時(ネットワークエラー・レート制限・APIキー不正等)は`st.error`でエラー内容をユーザーにわかりやすく表示する。

## テスト方針

- 個人用の小規模ツールのため、重厚な自動テストは組まない。
- `utils/prompts.py`のプロンプト組み立て関数のみ、簡単な`pytest`で「期待した文字列が含まれるか」を軽く検証する(任意・最小限)。
- 動作確認は実際にStreamlitを起動してのUI手動確認を基本とする。
